# LLM
## 2026-10-06 Tue
### NLP 분야와 LLM의 등장 배경
- ChatGPT와 같은 대규모 언어 모델은 지난 수 년간 발전해온 심층 신경망 모델이며, 자연어 처리 분야에 새로운 시대를 열었다고 평가된다.
- LLM 이전에는 전통적인 방식으로 분류 작업 및 패턴 인식 작업을 수행했으며, 이러한 작업은 간단한 모델로도 처리가 가능하다.
  - 고전적인 방식과 현대적인 LLM 모두 자연어 처리, 즉 NLP 분야에 속한다.
  - 그러나 복잡한 이해와 생성 능력이 필요한 류의 작업은 고전적인 모델의 성능이 좋지 못했으며, LLM의 전문 분야에 해당한다.
- LLM은 사람의 언어를 이해하거나 생성하고 해석하는 능력을 갖추는 반면, 사람과 같은 이해력이나 의식을 갖고 있다고 볼 수는 없다.
  - 즉, LLM은 어디까지나 일관성 있고 맥락에 맞도록 텍스트를 처리하고 생성하는 데에 초점을 맞춘다.
- 신경망은 머신러닝과 인공지능의 하위 분야 중 딥러닝의 발전에 힘입어 대량의 텍스트 데이터를 기반으로 훈련된다.
  - 이러한 대규모 훈련 덕에 LLM은 사람의 언어에 포함된 미묘한 뉘앙스와 문맥을 깊이 있게 이해할 수 있다.
- 단적으로 말해, **LLM은 이를 기반하는 트랜스포머 구조와 방대한 훈련 데이터 덕분에 성공**했다고 볼 수 있다.
  - **트랜스포머 구조를 기반으로 모델을 구현한 후, 대규모 훈련 데이터셋으로 LLM을 훈련하는 방식은 NLP 분야를 근본적으로 바꾸어놓았다**.

## 2026-10-07 Wed
### LLM이란?
```
> LLM은 사람의 텍스트를 이해하고, 생성하고 응답할 수 있도록 제안된 신경망이다.
```
- **LLM과 같은 모델은 대용량의 텍스트 데이터를 기반으로 훈련되는 심층 신경망이며, 인터넷에 공개된 전체 텍스트 중 상당수를 기반으로 훈련**된다.
  - 대규모 언어 모델이라는 이름에서 알 수 있듯, 대규모란 모델의 파라미터 크기와 훈련 데이터셋의 크기 모두를 지칭한다.
  - 이러한 모델은 시퀀스의 다음 단어를 예측하도록 훈련하는 과정에서 조정되는 신경망의 가중치인 파라미터를 수백 또는 수천억 개 이상을 갖는다.
- `next-word prediction` 기법은 언어의 고유한 순차 특징을 통해 텍스트 안의 맥락과 구조 및 관계를 이해하도록 모델을 훈련시키는 합리적인 방법이다.
  - 최근의 모델들은 이러한 간단한 작업 원리만으로 훈련되며, 그럼에도 매우 강력한 모델을 정의할 수 있게 된다는 점에 주목할 필요가 있다.
